# Model Licenses

Each redistributed model pack must have a dedicated directory here containing
an unmodified copy of the license that applied to the exact archived source
revision. Include required notices and attribution alongside it.

Do not add a model or mark a manifest entry as `ready` until commercial use,
redistribution, modification or quantization, attribution, and notice
requirements have been reviewed and recorded. A public source repository does
not by itself grant redistribution rights.

Do not place model binaries in this directory.
